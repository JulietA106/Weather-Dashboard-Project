# Weather Dashboard

A simple Weather Dashboard built with **React** and **Tailwind CSS**.
This project allows users to search for a city and view its weather information (to be connected with a weather API).

---

## Features

* Search for any city
* Responsive design using Tailwind CSS
* Input validation (alerts user if the search field is empty)
* Fully centered layout for better user experience

## Installation

1. Clone the repository:

```bash
git clone https://github.com/JulietA106/weather-dashboard.git
```

2. Navigate into the project directory:

```bash
cd weather-dashboard
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```
